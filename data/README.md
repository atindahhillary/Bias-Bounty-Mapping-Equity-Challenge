# Data in this folder

Everything here is generated by `python scripts/run_pipeline.py`, which queries the challenge's
public data directly from `source.coop/humane-intelligence/bias-bounty-mapping-equity-challenge`
(no credentials needed) and computes the real coverage-gap score per tract. Gitignored on
purpose -- it's a few hundred MB and reproducible from the pipeline, so it doesn't belong in git.

- `<region>-computed.csv` -- per-tract `transport_gap`/`building_gap`/`poi_gap`/`coverage_gap_score`
  plus each `*_defined` flag, exactly matching the challenge's own `<region>-sample-submission.csv`
  shape with the components filled in for real.
- `<region>-strata.csv` -- a slim strata subset (urban/rural, SVI, tribal, drought, wildfire,
  heat) for the Bias Discovery breakdowns. See `src/pipeline.py:STRATA_COLUMNS` to add more of
  the 232 available columns.
- `tracts.csv` -- all four regions' computed + strata data combined; this is what `app.py` loads.

## Method

Straight from the bucket's own README (`src/pipeline.py` implements this exactly, validated
against the published "218 of 591 northern-ca tracts have no named highway" figure):

- **transport_gap** = `1 - min(1, overture_length_m / tiger_length_m)`, named highways only
  (TIGER `S1100`/`S1200` vs Overture `motorway`/`trunk`/`primary`/`secondary`), lengths measured
  after clipping each road to the tract polygon and reprojecting to EPSG:5070.
- **building_gap** = `1 - min(1, overture_building_count / microsoft_building_count)`, both
  counted by centroid-in-tract.
- **poi_gap** = mean of the facilities half (mean of defined fire/EMS/schools gaps, each
  `1 - min(1, overture_count / hifld_count)` matched on `categories.primary`) and the
  establishments half (`1 - min(1, overture_places_total / cbp_estab_bus)`). Hospitals excluded.
- **coverage_gap_score** = mean of whichever of the three components are defined for that tract.
  A component is undefined (not zero) when the tract has nothing of that kind to compare
  against -- excluded from the mean rather than counted as full coverage.

## Re-running

```bash
python scripts/run_pipeline.py
```

Cached per region -- if `data/<region>-computed.csv` already exists it's loaded from disk
instead of recomputed, so a partial run (or a retry after a network hiccup) doesn't waste work
already done. Delete a specific file to force a recompute of just that region.
